# ArchiFlow - Легкий архиватор

## Описание
ArchiFlow - это современный, легкий архиватор для Windows с поддержкой популярных форматов архивов. Программа имеет интуитивно понятный интерфейс и интегрируется в контекстное меню Windows для быстрого доступа к функциям архивации.

## Возможности
- Поддержка форматов: ZIP, 7Z, RAR, TAR, GZIP, BZIP2 и других
- Интеграция в контекстное меню Windows
- Шифрование архивов с паролем
- Многоуровневое сжатие
- Разделение архивов на тома
- Современный интерфейс с поддержкой тем
- Drag-and-drop поддержка
- Многоязычный интерфейс (Русский, Английский)

## Системные требования
- Windows 7/8/10/11 (32-bit или 64-bit)
- 512 MB RAM
- 50 MB свободного места на диске
- Microsoft Visual C++ 2015-2022 Redistributable

## Установка
1. Запустите установщик ArchiFlow_Setup.exe
2. Следуйте инструкциям мастера установки
3. Выберите необходимые компоненты для установки
4. После установки программа будет доступна через:
   - Ярлык на рабочем столе
   - Меню Пуск
   - Контекстное меню (правая кнопка мыши)

## Использование

### Контекстное меню
1. Выберите файлы или папки
2. Нажмите правой кнопкой мыши
3. Выберите "ArchiFlow" -> "Добавить в архив"
4. Настройте параметры архивации
5. Нажмите "OK"

### Основное окно программы
- Перетащите файлы в окно программы для архивации
- Дважды щелкните архив для просмотра содержимого
- Используйте меню для дополнительных операций

## Сборка из исходников

### Требования
- Visual Studio 2019 или выше
- Windows SDK
- libarchive библиотека

### Инструкция по сборке
1. Клонируйте репозиторий
2. Установите libarchive в папку проекта
3. Откройте ArchiFlow.sln в Visual Studio
4. Выберите конфигурацию Release
5. Соберите проект
