# Инструкция по настройке контекстного меню для ArchiFlow

## Шаг 1: Импортируйте реестр
Двойной клик по файлу `register_context_menu.reg` или выполните в командной строке:
```
reg import "E:\ArchiFlow\register_context_menu.reg"
```

## Шаг 2: Использование

### Вариант 1: Drag&Drop (рекомендуется)
1. Откройте ArchiFlow
2. Перетащите файлы в окно программы
3. Программа создаст архив с выбранными файлами

### Вариант 2: Контекстное меню
1. Откройте проводник Windows
2. Кликните правой кнопкой по пустому месту в папке
3. Выберите "Create archive with ArchiFlow"
4. Программа откроется и попросит выбрать файлы

## Примечание
- Drag&Drop позволяет перетаскивать несколько файлов сразу
- При использовании контекстного меню будет открыт диалог выбора файлов
